# ZZZ Drive Disc Simulator

## 概要

『Zenless Zone Zero（ゼンレスゾーンゼロ）』のドライバディスク強化をシミュレーションするJavaFXデスクトップアプリです。

モンテカルロ法を使用して、指定したサブステータスが目標回数まで強化される確率を計算します。

現在のディスクの状態や強化条件を設定し、シミュレーション結果を確認・保存できます。

## 主な機能

- ドライバディスクの現在レベルとサブステータスの設定
- サブステータスの初期値入力
- 目標とする2種類のステータスと必要強化回数の指定
- 1,000回・10,000回・100,000回のモンテカルロシミュレーション
- 4つ目のサブステータスが未生成の場合の新規生成処理
- 強化成功確率と平均強化回数の計算
- ステータスごとの強化回数や期待値の表示
- シミュレーション結果に基づく判定・推奨情報の表示
- SQLiteによるシミュレーション結果の保存
- 保存した結果の履歴表示
- シミュレーション結果のクリップボードへのコピー
- 日本語・英語の表示切り替え
- 操作方法を説明する画面

## シミュレーションの仕組み

1. 現在のドライバディスクのレベルとサブステータスを入力します。
2. 強化したい2種類のステータスと、それぞれの必要強化回数を設定します。
3. 指定した回数だけランダムな強化処理を繰り返します。
4. 各シミュレーションで目標条件を満たしたか判定します。
5. 成功回数から確率を計算し、平均強化回数や期待値とともに結果を表示します。

4つ目のサブステータスが存在しない場合は、最初に新しいステータスを生成してから残りの強化を行います。

## 実行方法

Java 17以上とMavenを使用します。

`pom.xml`があるプロジェクトフォルダで、以下のコマンドを実行します。

`mvn javafx:run`

## ファイル構成

| ファイル | 内容 |
|---|---|
| `App.java` | メイン画面、入力処理、画面遷移 |
| `Launcher.java` | アプリケーションの起動 |
| `Main.java` | モンテカルロシミュレーションと確率計算 |
| `DatabaseManager.java` | SQLiteデータベースの初期化、保存、読み込み |
| `SimulationResult.java` | 保存結果のデータ管理 |
| `StartScreenView.java` | スタート画面とアニメーション |
| `MenuScreenView.java` | メニュー画面 |
| `StatData.java` | サブステータスの定義 |
| `StatValueData.java` | ステータスの数値と単位の管理 |
| `TextData.java` | 日本語・英語の表示テキスト |
| `menu.css` | 画面デザイン |
| `pom.xml` | Mavenの設定 |

## データベース

SQLiteの`simulation_results`テーブルにシミュレーション結果を保存します。

保存される情報には、ディスクの設定、シミュレーション回数、成功確率、判定結果、実行日時などが含まれます。

保存した結果はアプリ内のHistory画面から確認できます。
